【威胁情报报告】 伪猎者APT组织（WPS/Foxmail 0day漏洞攻击链）
====================================================================

报告编号: CTI-2024-005
发布时间: 2024年8月
情报来源: 安全星图平台、Dbappsecurity、奇安信威胁情报中心
置信度: 高 (可信度: 93%)

一、威胁概述
------------
伪猎者（Internal Blue、APT-C-60）是一个具有韩国政府背景的高级持续性威胁组织，长期针对中国境内的高价值目标开展间谍活动。该组织最显著的特点是掌握大量针对中国用户常用本地化软件的零日漏洞武器库，能够在受害者毫无察觉的情况下实现零点击远程代码执行。2024年，该组织被确认掌握了至少3个针对国产办公软件和邮件客户端的零日漏洞，形成了完整的"邮件到主机"攻击链。

二、攻击目标
------------
【主要受害行业】
- 中国政府部门和党政军机构
- 国防军工企业
- 高科技制造业
- 科研院所和高校
- 大型企业集团
- 金融保险机构

【受害者特征】
- 使用WPS Office作为主要办公软件
- 使用Foxmail或网易邮箱大师处理邮件
- 使用126/163邮箱服务
- 在特定大型企业任职或与特定企业有业务往来

【定向性特征】
该组织展现出明显的目标定向能力，部分攻击活动针对特定企业的员工进行精准打击，表明该组织拥有较强的情报收集和目标画像能力。

三、攻击向量与技战术分析
------------------------
【攻击链总览】
该组织的攻击链通常由三个阶段组成：
1. 情报收集阶段：通过开源情报和社工手段收集目标个人信息
2. 钓鱼诱饵阶段：通过精心构造的邮件或文档触发漏洞
3. 后渗透阶段：部署持久化后门，窃取敏感数据

【WPS Office零日漏洞（CVE类漏洞）】
伪猎者掌握的WPS Office零日漏洞具有以下特点：

1. 攻击向量：精心构造的电子表格（.et）文件
2. 触发条件：用户单击嵌入的图片对象即可触发漏洞，无需其他交互
3. 漏洞类型：远程代码执行漏洞，允许攻击者在受害者系统上执行任意代码
4. 攻击手法升级：与传统需要宏代码的钓鱼攻击不同，该漏洞实现了真正的"单击即沦陷"
5. "轻办公"链接投毒：攻击者还利用WPS的"轻办公"协作功能，通过分享链接植入恶意代码，当受害者点击链接时自动执行恶意命令

【Foxmail零日漏洞】
Foxmail是中国用户广泛使用的邮件客户端，伪猎者掌握的Foxmail漏洞是该组织最危险的武器之一：

1. 漏洞类型：零点击远程代码执行漏洞
2. 触发方式：用户打开攻击者发送的特制邮件即可触发，无需任何点击或交互
3. 执行时机：邮件在预览窗口加载时即触发漏洞，恶意代码自动执行
4. 免杀能力：漏洞载荷经过精心设计，能够绕过主流杀毒软件的实时监控
5. 持久化机制：成功执行后会部署多级后门程序，建立持久化访问通道

【126/163邮箱XSS漏洞利用】
伪猎者还针对中国用户常用的网易邮箱服务发动攻击：

1. 漏洞类型：存储型跨站脚本（XSS）漏洞
2. 攻击目标：126邮箱和163邮箱的Web界面
3. 攻击目的：窃取邮箱Cookies和会话令牌
4. 传播方式：攻击者向目标发送带有恶意脚本的邮件，当邮件被受害者查看时，脚本自动执行
5. 数据外泄：通过窃取的Cookie，攻击者可以无需密码登录受害者邮箱，访问所有历史邮件和联系人信息

【分阶段载荷投递技术】
伪猎者采用高度模块化的载荷投递策略：

1. 第一阶段投递物：诱饵文档（通常为.pdf、.doc或.et格式）
2. 载荷激活后：释放白加黑组件，利用合法Windows组件执行恶意代码
3. 使用的白文件：
   - shimgvw.dll（Windows图像和传真查看器组件）
   - pcalua.exe（Windows程序兼容性助手）
4. 加密手段：使用改良的base64算法对恶意载荷进行编码，增加检测逃避能力
5. 定制化生成：针对不同受害者定制化生成不同的执行命令和载荷配置

【后渗透与数据窃取】
成功渗透后，攻击者通常执行以下操作：

1. 凭证收集：使用Mimikatz等工具提取系统凭据
2. 横向移动：通过窃取的凭据访问网络中的其他系统
3. 数据打包：使用7-Zip等工具将敏感文件压缩为加密存档
4. 数据外泄：通过HTTP/HTTPS协议将数据外泄到C2服务器
5. 持久化维持：通过注册表RUN键值或WMI事件订阅维持持久化

四、关联基础设施
----------------
【C2服务器特征】
- 攻击者使用的C2服务器通常位于境外
- 部分C2节点伪装为合法的软件更新服务器
- 使用HTTPS协议进行加密通信，伪装为正常Web流量
- 定期更换IP地址和域名，增加追踪难度

【攻击时间规律】
- 钓鱼邮件通常在工作日发送，模拟正常业务沟通
- C2通信发生在非工作时间，减少被发现的机会
- 攻击活动通常持续数周甚至数月后才被发现

五、攻击活动时间线
----------------
2019年：首次发现针对中国目标的定向攻击活动
2021年：确认使用WPS Office漏洞
2022年：发现Foxmail零日漏洞利用
2023年：扩大攻击范围至大型企业
2024年：持续针对高价值目标，使用多漏洞组合攻击
2024年中：安全厂商发布预警，WPS和Foxmail厂商紧急修复漏洞

六、检测与防御建议
-----------------
【针对邮件威胁】
1. 部署邮件安全网关，对入站邮件进行深度内容检测
2. 启用邮件附件沙箱分析，识别恶意文档
3. 对Foxmail和网易邮箱Web版实施额外的安全监控
4. 提醒用户不要点击可疑邮件中的链接或附件

【针对本地化软件漏洞】
1. 立即更新WPS Office到最新版本
2. 及时安装Foxmail安全更新补丁
3. 考虑使用企业版WPS，获取更快的安全更新支持
4. 对办公软件禁用宏功能和外部内容自动加载

【针对网络威胁】
1. 部署网络流量分析系统（NTA），检测异常的C2通信
2. 监控出站HTTPS流量的异常模式
3. 对DNS请求进行白名单过滤，阻止未知域名解析
4. 实施最小权限原则，限制办公设备的网络访问范围

【通用防护措施】
1. 定期进行安全意识培训，提高员工警惕性
2. 实施强密码策略并启用多因素认证
3. 定期备份重要数据，确保可恢复性
4. 部署端点检测响应（EDR）系统
5. 建立应急响应流程，快速处置安全事件
